# Security audits

Audits are **dated, immutable snapshots** — each is pinned to the commit it reviewed and is not edited afterwards (except for a resolution-status table tracking how findings were addressed). File paths and API names inside an audit reflect the repository at audit time, not necessarily the current tree.
